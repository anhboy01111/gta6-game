## About
A high-performance open-world crime action game built for the web with pure modern web technologies (HTML5 Canvas / WebGL, ES modules, zero external dependencies).

### Features
- **Open-World Vice City Environment**: Sprawling urban cityscape with neon lighting, dynamic day/night atmospheric lighting, oceanfront promenade, and diverse districts.
- **Player & Driving Dynamics**: Smooth on-foot movement, sprinting, car theft, realistic vehicle handling physics, responsive camera follow, and collision detection.
- **Living City Simulation**: Autonomous pedestrian NPCs, dynamic traffic flow, and reactive urban behaviors.
- **Wanted Level & Police Chase AI**: Escalating 1 to 5 star wanted level with tactical police cruisers and pursuit logic.
- **Crime Missions & HUD**: Interactive missions, high-contrast minimap radar, health, armor, weapon, and cash indicators.

## Playing Locally
```bash
node serve.ts
```
Open `http://localhost:8080` in your desktop web browser.
